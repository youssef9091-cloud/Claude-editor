# ChatGPT image prompts — rig-ready sheets

How to use: open a **new ChatGPT chat per character / set**. Attach the existing sheet image
(father sheet, daughter sheet, or location sheet), paste the **STYLE LOCK** first, then send the
sheets one message at a time. Download each result as PNG and upload them here.

If the background comes out checkered or grey instead of transparent, reply:
"Same image, but on a flat pure green #00FF00 background."

---

## STYLE LOCK (paste first, in every chat)

```
Use the attached character sheet as the exact reference. Keep the character 100% on-model:
same face, skin tone, hair, beard, glasses, outfit, colours and proportions. Art style:
clean flat 2D cartoon illustration, flat cel shading with one soft shadow tone, consistent dark
brown outlines (#33241b), no texture, no gradients, no painterly brushwork. Every image I ask for
is a production sheet for 2D cut-out animation: parts must be fully drawn (no hidden overlaps
missing), evenly lit from the front-left, isolated, on a transparent background, no text labels,
no logos, no cast shadows on the ground. Keep the same scale for every part in a sheet.
Reply with images only.
```
